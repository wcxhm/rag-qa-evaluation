# API 鉴权与限流

## 鉴权方式

开放平台采用 OAuth2 的 client_credentials 模式，调用方使用 app_id 与 app_secret 换取 access_token。access_token 有效期 2 小时，建议在到期前 5 分钟刷新，重复换取会使旧 token 在 60 秒后失效。所有请求必须携带 Authorization 头，签名算法为 HMAC-SHA256。

## 限流策略

默认限流为每租户 100 QPS，允许 200 QPS 的瞬时突发，超出后返回 429 状态码并附带 Retry-After 响应头。不同接口可以单独申请配额，批量查询接口的配额按每次请求的记录数折算。限流按 app_id 维度统计，同一租户下多个应用不共享配额。

## 重试与错误码

调用方遇到 429 或 5xx 时应使用指数退避重试，初始间隔 0.5 秒，最多重试 3 次，总耗时不超过 10 秒。400 与 401 不应重试，需要先修正参数或刷新 token。平台保证同一请求在 5 分钟内的幂等性，重复提交不会产生额外计费。

## 版本管理

API 采用日期版本号，例如 2026-03-01，旧版本至少维护 12 个月。版本下线前 90 天通过邮件与公告通知调用方。新增字段属于兼容变更，不触发版本升级；删除字段或修改语义必须升级版本。
