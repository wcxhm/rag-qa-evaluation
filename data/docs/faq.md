# 客户常见问题

## 接入与部署

平台支持 SaaS 与私有化两种交付方式。SaaS 方式开通后 30 分钟内可用，私有化交付的标准周期为 6 到 8 周。接入方式分为 Agent 采集与无 Agent 拉取两种，Agent 支持 Linux 与 Windows Server 2016 及以上版本。是否支持信创环境需要单独评估，目前已完成鲲鹏与麒麟的兼容性测试。

## 计费方式

计费按纳管采集目标数量分档，100 个目标以内为基础版，100 到 1000 个为专业版，超过 1000 个按阶梯单价结算。日志存储按实际用量单独计费，每 GB 每月 0.8 元。新客户提供 30 天免费试用，试用期包含全部专业版功能，但不包含专属技术支持。

## 数据迁移

从其他监控系统迁移时，平台提供指标映射工具，支持将原有的仪表盘与告警规则批量导入，规则需要人工确认阈值后才能启用。历史指标默认不迁移，如有需要可以通过离线导入方式补录最近 90 天的数据。迁移工具支持 Prometheus、Zabbix 两种数据源。

## 服务支持

标准服务时间为工作日 9:00 到 18:00，P0 故障提供 7x24 小时支持。专属技术经理需要购买企业版后配置，响应时限为 30 分钟。产品问题可以通过工单、企业微信群、400 电话三个渠道反馈，工单平均首次响应时间为 2 小时。
