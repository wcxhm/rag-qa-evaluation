# 数据分级与权限管理

## 数据分级

公司数据分为 L1 到 L4 四级。L1 为公开数据，L2 为内部数据，L3 为敏感数据，L4 为核心数据。L3 及以上数据必须加密存储，静态加密算法为 AES-256，密钥由密钥管理服务统一托管并每 90 天轮换一次。L4 数据禁止导出到个人设备。

## 权限模型

权限采用 RBAC 模型，角色分为查看者、编辑者、管理员、审计员四类。权限申请需要直属主管审批，L3 数据还需要数据Owner 二次审批，审批有效期最长 180 天，到期自动回收。越权访问会触发实时告警并记录到安全事件库。

## 审计与留痕

所有数据访问、导出、权限变更都会写入审计日志，日志保留 180 天且不可篡改。审计员可以按用户、时间、数据等级三个维度检索。批量导出超过 1000 条记录时需要额外填写用途说明，单次导出上限为 5 万条。

## 跨租户隔离

租户之间在网络、存储、密钥三个层面隔离，禁止跨租户的数据关联查询。因业务需要做联合分析时，必须使用脱敏后的样本数据，并在独立的分析环境中完成。脱敏规则由安全团队维护，业务方不得自行修改。
